# Pirineo Ecuestre – SQL Project

## This project models and analyzes a booking system for a real equestrian activities' company based in the north of Spain.

My goal is to demonstrate SQL skills applied to a real business scenario, since this company operates since 2000.

## Explanation of the Database design
- Relational database with 4 tables:
  - Servicios
  - Clientes
  - Reservas
  - DetallesReservas
- Primary and foreign keys

## Business Analysis
- Revenue by service
- Revenue by country
- Service profitability ranking

## Reporting
- SQL View (`vw_ReservasDetalle`) ready for applying it into Power BI or Excel in order to analyze it

## SQL Features Used
- CREATE DATABASE / TABLE
- INSERT
- JOINs
- Aggregations (SUM)
- GROUP BY / ORDER BY
- VIEW
- FUNCTION (scalar)

## How to Run
1. Open SQL Server Management Studio
2. Run the script `pirineo_ecuestre.sql`
3. Execute the analysis queries
